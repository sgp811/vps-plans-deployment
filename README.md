## 购买前需要准备什么？

你需要：

**2. 真实账单信息**

需要提供真实准确的法定姓名和居住地址。所有订单会经过反欺诈系统和人工审核。如果系统检测到信息不准确、疑似欺诈或曾有滥用记录，订单会被拒绝并退款。

审核通常是自动的，付款成功后几分钟内就能完成。只有在系统标记可疑的情况下，才会有人工介入，这种情况可能需要几小时到一天。

**3. 域名（可选）**

如果你打算用独立域名，可以在 V.PS 一起注册域名，或者先在其他地方买好域名再填入。域名不是必需的，服务器会分配 IP 地址，你可以直接用 IP 访问。

### 3. 填写配置选项

系统会要求你选择操作系统。V.PS 支持：

在选择完套餐和计费周期后，进入结账页面。页面上通常有一个「Promo Code」或「Promotional Code」输入框（通常在订单摘要的下方或右侧）。

### 5. 完成支付

检查订单信息：套餐、机房、计费周期、价格。确认无误后点击「Checkout」或「Complete Order」。

选择支付方式，完成付款。付款后系统会自动处理订单，通常几分钟内就能看到结果。

付款成功且通过反欺诈审核后，V.PS 会自动设置服务器。不需要提交工单，不需要等人工确认。通常几秒到几分钟内，服务器就会出现在你的客户区「Services」列表里，状态显示为「Active」。

你会收到一封邮件，里面包含：

用 SSH 客户端（Windows 可以用 PuTTY 或 Windows Terminal，Mac 和 Linux 直接用终端）连接服务器 IP，输入用户名和密码，就能登录了。

登录服务器后，你可以：

- **重启、重建、调整规模**：在客户区的服务管理页面，有「Reboot」「Rebuild」等按钮，可以重启服务器或重装系统。V.PS 还支持通过 API 脚本化操作这些功能。

- **升级套餐**：随时可以通过提交工单申请升级到更高配置。折扣产品不提供折扣价升级，会按新套餐原价计费。

## 退款政策与限制

V.PS 的 VPS 产品可以在 14 个自然日内通过提交工单申请退款。但退款有不少限制，这些限制在官网写得很清楚，买之前最好看一下：

**不能退款的情况**：
- 已经申请过退款（每个账户只能退款一次）
- 已使用超过 10 GB 数据传输
- 有与服务器相关的活跃 BGP 或 IX 服务
- 服务是从其他客户转移到你的账户，或者你已经把服务转移给其他账户
- 有滥用报告，或者 VPS IP 被列入任何黑名单（Spamhaus、blocklist.de、GFW of China 等）
- 已申请 IP 更换
- 加密货币和银行转账付款不可退
- 续费订单不可退
- 限时折扣产品（flash sale）不可退

换句话说，如果你买了之后只是轻度测试（流量别超 10GB），没有做任何违规操作，14 天内可以退。但如果你已经跑了大流量，或者 IP 被墙了，就退不了。

域名注册、转移和恢复不提供退款。SSL 证书有 30 天退款保证。

## 常见问题

### 能换机房吗？

不能直接换。你需要在新机房订购新服务器，手动把数据迁移过去，然后取消旧服务器。

### 套餐之间能升级吗？

可以。随时可以通过提交工单申请升级。折扣产品升级时不保留折扣，按新套餐原价计费。

### 流量超了怎么办？

V.PS 的流量是计算双向的（上传+下载）。官网没有明确说超流量后会怎样，通常的做法是限速或按量计费。建议提前在客户区查看流量使用情况，如果接近上限可以提前升级套餐。

### 能用来干什么？

合法用途都可以。常见场景包括：个人博客、测试环境、API 服务、小型数据库、科学上网（前提是符合你所在国家和服务器所在国家的法律）、爬虫、CI/CD 等。

不能用来做的事情：垃圾邮件、DDoS 攻击、非法内容托管、侵犯版权的活动等。违规会直接封号且不退款。

### 备份包含在套餐里吗？

Cloud KVM 套餐（包括 Starter、Essential）不包含自动备份，需要额外购买。Performance 套餐内含备份。你也可以自己用工具定期备份到本地或对象存储。
